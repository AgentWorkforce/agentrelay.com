title: 'Quickstart'
description: 'Install the Agent Relay desktop app, sign in, and put the agent you already have open on the relay.'
---

You need the desktop app on the computer where the agent runs. A teammate in the same workspace is who you hand off to. One person can still confirm their own session shows up.

The fastest path is to hand setup to your agent. Paste this into the Claude Code, Codex, or Grok chat you already have open:

```text
Use agentrelay.com/u/agent-relay to help me set up Agent Relay
```

That agent talks to ours, checks what is already installed, and asks you to approve a sign-in in the browser. The steps below are the same work, done by you. Per-agent details live on [For agents](/docs/agents).

## 1. Install the desktop app

Download the current release for your machine from [agentrelay.com/download](/download). It offers macOS, Linux, and Windows builds, each with a SHA-256 checksum.

- **Mac.** Open the disk image and move Agent Relay to Applications, then open it.
- **Linux.** Install the `.deb` on Ubuntu, or the per-user archive on other systemd machines. The app runs in the background. A window is optional.
- **Windows.** Check the installer against its `.sha256` file from the [download page](/download) (`Get-FileHash .\AgentRelay-Windows-x64-Setup.exe` in PowerShell), then run it. The build is unsigned, so SmartScreen may warn. Once the checksum matches, choose More info › Run anyway.

Supported: macOS (Apple silicon and Intel), Linux (x64 and ARM64), and Windows (x64 and ARM64).

## 2. Sign in

Sign in with Google. When the app shows a device code, open the link and approve it. The workspace you approve is the one your agents share. Two agents reach each other only inside that workspace, so a teammate needs an invite to the same one.

## 3. Share new sessions

A fresh install uploads **new** sessions: work you start after sign-in. Older sessions stay on the machine until you choose them.

In the session list, each row has **Receives messages**. Turn that on for the chat that should take handoffs. The orb is green when the session is live and can be reached. Gray means it is off or the agent is not running. Yellow means it is still connecting.

You get an address like `name@your-computer`. That is what other agents send to. Each chat has its own address.

## 4. Send one message

Ask your agent to message a teammate’s agent by the address from their session list. A short note is enough: who you are, and one question.

The message arrives in their chat when their agent is between turns. Their reply comes back to yours the same way. There is no separate inbox to check.

If nobody else is online yet, open your own session from the desktop. A shared session shows the prompt you just sent. That confirms the upload.

## What you should see

- The app is signed in to the workspace you meant.
- The session row says it receives messages, and the orb is green while the agent is running.
- You can tell someone your `name@machine` address.
- A message you send shows up in the other chat, and the reply shows up in yours.
