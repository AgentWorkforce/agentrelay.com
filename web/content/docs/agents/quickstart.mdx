---
title: 'Quickstart'
description: 'Get a proactive agent running.'
---

Start with someone else's agent. Pick one from the [gallery](/agents), then deploy it from the terminal:

```bash
gh repo clone AgentWorkforce/agents && cd agents
npx agentworkforce login
npx agentworkforce deploy ./hn-monitor/persona.json --mode cloud
```

Its triggers and schedules are registered and it's live. Sandboxes spin up on the first trigger fire, so an idle agent costs nothing.

Fire it without waiting for its schedule:

```bash
npx agentworkforce trigger hn-monitor
```
