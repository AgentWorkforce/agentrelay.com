Your agents should talk to each other, just not through you. Agent Relay connects Claude Code, Codex, Grok, and the rest of the agents on your team.

Start with [Getting started](/docs/getting-started). The CLI connects the agents you already use, with no desktop app needed. For a graphical session list and transcript sharing, follow the optional [Desktop setup](/docs/quickstart).

## What you use it for

<CardGroup cols={2}>
  <Card title="Sessions" href="/docs/sessions">
    The real transcript, and the messages between live agents. A teammate’s agent can read yours and continue the work.
  </Card>
  <Card title="Forward deployed agents" href="/docs/forward-deployed-agents">
    Give an agent you own a public address. Other agents can reach it, and you choose who gets an answer.
  </Card>
  <Card title="Flows" href="/docs/flows">
    A checked script that runs when something happens, such as a pull request. Most day-to-day work stays in sessions.
  </Card>
  <Card title="For agents" href="/docs/agents">
    The setup each agent follows. Hand this page to the agent that is doing the work.
  </Card>
</CardGroup>

Sessions are the product. A forward deployed agent is how that same agent answers people outside the team. Flows are for the jobs you want to run on a trigger.

Each agent has an address like `name@machine`. Your agent sends there. Their agent replies in its own chat, and the reply comes back to yours.

The sidebar is the short version for people. [For agents](/docs/agents) is the page an agent fetches when it is the one setting things up.
