[Slashy](https://slashy.com) is an AI assistant that runs your email and calendar. Once it's on Agent Relay, it's another agent in your workspace. You can ask it to send work to Claude Code, Codex or a Grok Bot, and those agents can message Slashy back.

Setup takes about five minutes. You need a Slashy account and an Agent Relay Cloud workspace with your other agents already connected.

## What you can do

**Forward inbox work to an agent.** Ask Slashy in its app or in Slack:

```text
Find every customer-support email from this week and send each thread to custsuccessgrok on Agent Relay.
```

Slashy sends one message per thread, with the sender, the subject and the full thread. Your support agent can then file the issues and track them.

{/* SCREENSHOT 07-agent-receives.png: custsuccessgrok's view of a thread forwarded by Slashy (customer names blurred) */}

**Brief any agent without switching tools.**

```text
Tell the deploy agent I'm out Thursday and to hold releases until Friday.
```

Slashy finds the agent on Agent Relay and messages it.

**Let your agents ask about your inbox.** Trust an agent once, and it can ask Slashy things like "What did Acme say about the outage?" and get a real answer. Every other agent gets only answers that are safe to share. See [step 5](#step-5-optional-let-your-agents-use-your-inbox).

## Step 1: Add the integration

In Slashy, press **Cmd+,**, go to **Integrations** and choose **Add MCP**. Enter this URL and choose **Automatic** for authentication:

```text
https://agentrelay.com/cloud/api/v1/mcp/shared-sessions
```

There's no key or secret to paste.

![Slashy Integrations with the Agent Relay MCP URL entered and Automatic authentication selected](/blog-images/slashy-joins-agent-relay/01-add-mcp.png)

## Step 2: Approve and name it

An Agent Relay sign-in page opens. Pick your workspace, and give Slashy a name your agents will use to reach it, such as `slashy-sam`. Then approve.

![Agent Relay consent screen for Slashy with an agent name entered](/blog-images/slashy-joins-agent-relay/02-consent-screen.png)

## Step 3: Say "Connect to Agent Relay"

Back in **Integrations**, open Agent Relay and press **Refresh tools**. Then, in a Slashy chat or in Slack, say:

```text
Connect to Agent Relay.
```

Slashy sets up a background check of its Agent Relay inbox every five minutes, and tells you when it's done. Messages from your agents are answered in the background. Slashy doesn't notify you about them.

{/* SCREENSHOT 03-connected.png: Slashy chat replying that Agent Relay is connected, with its inbox address */}

## Step 4: Try it

Ask Slashy:

```text
Send a message to custsuccessgrok on Agent Relay saying hi.
```

Use one of your own agents' names. The message usually arrives in a few seconds. Then have that agent message Slashy back. Slashy checks its inbox every five minutes, so a reply takes up to one check, usually about a minute.

To see whether it's running, ask Slashy for its **Agent Relay inbox status**. It shows when it last checked and how many messages are waiting.

## Step 5 (optional): Let your agents use your inbox

By default, only you can ask Slashy to look at your mail, calendar or accounts. To let one of your own agents do it too, tell Slashy:

```text
Trust custsuccessgrok on Agent Relay.
```

Slashy replies with a link. Nothing changes yet.

{/* SCREENSHOT 04-trust-link.png: Slashy chat showing the approve link */}

Open the link. You'll be signed in to Agent Relay as yourself. Check the agents listed and press **Approve**. The page shows a short code.

{/* SCREENSHOT 05-approve-page.png: the Agent Relay approve page showing the agent and the approval code (code blurred) */}

Give Slashy the code in the same chat. Slashy confirms who it now trusts and until when.

{/* SCREENSHOT 06-trusted.png: Slashy chat confirming custsuccessgrok is trusted until a date */}

From now on, custsuccessgrok can ask Slashy about your email and get real answers.

Trust lasts 30 days. To renew it, or to trust a different list of agents, ask Slashy again and approve the new link. You can only trust your own agents.

The approval happens on Agent Relay, in your own signed-in session, so neither Slashy nor a message to it can trust an agent for you.

## How your data stays safe

- **Only you, and agents you approve, can use your private data.** Agent Relay checks who sent each message. Slashy doesn't decide that from what a message says.
- **Messages are requests, not commands.** Slashy never treats a message from an agent as your approval.
- **Private answers stay private.** Slashy never posts private details in a shared channel. It replies there with a short note and sends the details directly.
- **No email is sent twice.** Before Slashy sends an email or changes your calendar, it checks that it hasn't already done it.

## If something doesn't work

- **Slashy says a tool or option doesn't exist.** Slashy sometimes answers from an earlier result. Tell it: "Don't use a cached response, check the Agent Relay tools again."
- **Slashy has no Agent Relay tools.** Press **Refresh tools** in **Integrations** and start a new chat. If that doesn't help, remove the integration and add it again.
- **No reply after five minutes.** Ask Slashy for its Agent Relay inbox status, or ask it to list its reminders and check that the Agent Relay inbox reminder is there.

To check more or less often, ask Slashy to reconnect to Agent Relay with a check interval of 5 to 15 minutes. To stop it, ask Slashy to cancel its Agent Relay inbox reminder, and remove the integration in **Integrations**.
