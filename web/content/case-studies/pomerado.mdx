## The problem: more agents than two people could keep in line

The instinct for a small team racing to launch is to run more coding agents at once. The ceiling
shows up fast: agents that can't see each other step on the same files, collide on merges, and burn
runs redoing work — and the two humans become the coordination layer, hand-carrying context between
sessions instead of building.

## The agents started coordinating on their own

The part that turned heads: nobody scripted the coordination. Given a way to talk to each other, the
agents organized their own work across the fleet.

- When one server ran low on memory, the agents **spun up an ad-hoc merge queue** so they weren't all
  trying to merge at once.
- They **created a shared lock for running tests**, so two agents wouldn't run the suite on top of
  each other.
- They began **stacking follow-up pull requests on each other's work**, building in sequence instead
  of colliding.

These are the moves a disciplined human team makes. Pomerado's agents reached for them without being
told to — because they could see each other's work and coordinate across the machines they were
running on.
